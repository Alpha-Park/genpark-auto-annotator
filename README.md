# genpark-auto-annotator

Zero-shot computer vision dataset labeler.

Stop paying for closed SaaS apps. This is a terminal-native, open-source alternative to **T-Rex Label**.

A pure vision-API wrapper script. Feed it a folder of images, and the agent identifies bounding boxes and generates COCO-format JSON annotations locally for free.

## Usage
```bash
openclaw use genpark-auto-annotator
```
